# Відеодовідка

У «Допомозі» доступні шість коротких відео: запис у чергу, завершення здачі, обміни, оформлення, встановлення PWA на телефон і на ПК. Кожне триває приблизно 30 секунд. Відео без звуку, з українськими поясненнями та позначенням натискань; програвач також має WebVTT-підписи й текстову інструкцію.

Записано справжній інтерфейс із локально підставленими тестовими даними. Реальні профілі, робоча база, Telegram-повідомлення й дії на Render не використовувалися. Кроки встановлення поза сторінкою показані як текстові підказки «Крок у браузері», а не як запис системного діалогу встановлення.

Інструкції для Safari звірено з [Apple: Turn a website into an app in Safari on iPhone](https://support.apple.com/guide/iphone/iphea86e5236/ios). Для Chrome — з [Google: Use web apps](https://support.google.com/chrome/answer/9658361). Назви пунктів залежать від версії браузера й мови системи.

## Відтворення записів

`scripts/record_help_videos.cjs` автоматизує реальні натискання у локальній мініапці. Усі мережеві запити перехоплюються fixture: скрипт не звертається до production. Потрібні Playwright, його компонент FFmpeg для запису та окремий FFmpeg з H.264 для експорту:

```text
node scripts/record_help_videos.cjs [playwright-module] [output-directory] [ffmpeg-executable] [optional-topic]
```

Теми: `join`, `complete`, `swap`, `appearance`, `install-phone`, `install-desktop`. Без теми записуються всі шість. Результат — MP4 H.264/yuv420p/24 fps з `faststart`, JPEG-обкладинка та VTT для кожного ролика. Це інструменти створення матеріалів; встановлювати їх на Render не потрібно.

`help-videos.js` містить перевірений перелік роликів. `web.py` дозволяє лише ці конкретні імена файлів. Aiohttp FileResponse підтримує byte ranges для перемотування й метаданих у мобільних браузерах. Відео не включені до попереднього кешування PWA: допомога завантажує лише обкладинки; відеодані запитуються після відкриття ролика. Закриття вікна призупиняє відтворення.
