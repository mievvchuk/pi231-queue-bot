# Відеодовідка

У «Допомозі» доступні шість коротких відео: запис у чергу, завершення здачі, обміни, оформлення, встановлення PWA на телефон і на ПК. Кожне триває 40 секунд. Відео мають українську синтезовану озвучку, пояснення та позначення натискань; програвач також має WebVTT-підписи й текстову інструкцію.

Записано справжній інтерфейс із локально підставленими тестовими даними. Реальні профілі, робоча база, Telegram-повідомлення й дії на Render не використовувалися. Кроки встановлення поза сторінкою показані як текстові підказки «Крок у браузері», а не як запис системного діалогу встановлення.

Інструкції для Safari звірено з [Apple: Turn a website into an app in Safari on iPhone](https://support.apple.com/guide/iphone/iphea86e5236/ios). Для Chrome — з [Google: Use web apps](https://support.google.com/chrome/answer/9658361). Назви пунктів залежать від версії браузера й мови системи.

## Відтворення записів

Спочатку створіть аудіо за інструкцією нижче й передайте його каталог останнім аргументом.

`scripts/record_help_videos.cjs` автоматизує реальні натискання у локальній мініапці. Усі мережеві запити перехоплюються fixture: скрипт не звертається до production. Потрібні Playwright, його компонент FFmpeg для запису та окремий FFmpeg з H.264 для експорту:

```text
node scripts/record_help_videos.cjs [playwright-module] [output-directory] [ffmpeg-executable] [optional-topic] [narration-directory]
```

Теми: `join`, `complete`, `swap`, `appearance`, `install-phone`, `install-desktop`. Без теми записуються всі шість. Результат — MP4 H.264/yuv420p/24 fps та аудіо AAC із `faststart`, JPEG-обкладинка та VTT для кожного ролика. Це інструменти створення матеріалів; встановлювати їх на Render не потрібно.

`help-videos.js` містить перевірений перелік роликів. `web.py` дозволяє лише ці конкретні імена файлів. Aiohttp FileResponse підтримує byte ranges для перемотування й метаданих у мобільних браузерах. Відео не включені до попереднього кешування PWA: допомога завантажує лише обкладинки; відеодані запитуються після відкриття ролика. Закриття вікна призупиняє відтворення.

## Озвучка й темп

Сценарій озвучки та тривалості сцен: `scripts/help_video_narration.json`. Український голос `uk-UA-PolinaNeural`, темп `-5%`. Для повторного створення аудіо потрібен `edge-tts` лише в середовищі автора:

```text
python -m pip install edge-tts
python scripts/narrate_help_videos.py OUTPUT_DIRECTORY FFMPEG [optional-topic]
```

Сервісу синтезу передається лише відкритий текст навчальних пояснень. Профілі та дані студентів не використовуються. На Render не потрібні ключі чи нові залежності: голос уже вмонтовано в MP4. Проміжні MP3/WAV зберігаються поза статичними ресурсами; кеш фраз залежить від тексту, голосу й темпу. Скрипт вимірює кожну фразу та відмовляється обрізати слова, якщо вони не вміщуються в сцену.

Перед натисканням кнопка підсвічується 0,5 с; після натискання зображення утримується ще 1,5 с. Між діями є щонайменше дві секунди. Голос, титри та сцени використовують одну шкалу часу. Запис переривається помилкою, якщо дія не вклалася в свою сцену, замість накопичення розсинхронізації. У підказках про встановлення зовнішні кроки браузера залишаються явно позначеними текстовими вставками.

Відтворення починається лише після натискання Play; звук не вимкнений програмно. Під відео є перемикач швидкості 0,75× / 1× / 1,25×. Залишено українські WebVTT-підписи, що відповідають озвучці, й текстові інструкції. URL матеріалів містять версію, щоб старі беззвучні ролики не залишалися в кеші браузера.
