# Навігація адміністратора

Головна панель: черги, розклад, допомога, баг-репорт, «Режим студента»
і «Ще для адміна». Перемикання режиму стоїть перед додатковим меню й
доступне всім адміністраторам. У «Ще для адміна» — опитування, список
групи та налаштування власника. Створення черги перенесене до «Черги».
Черги постійні: закриття запису та завершення всієї черги прибрані.
Здача запускається й зупиняється за розкладом, без ручних кнопок.

«Оновити» у відкритій черзі редагує її повідомлення без повторного
надсилання списку та меню. Посилання на повідомлення розділені за ботом,
чатом, користувачем, чергою й режимом та зберігаються між перезапусками.
Якщо повідомлення видалене або Telegram більше не дозволяє його редагувати,
бот один раз надсилає новий список і надалі оновлює його. Відсутність змін
не вважається помилкою. Підписи про постійність черги прибрані з оглядів.

У студентському розділі «Усі черги» відкривається пошук за предметом,
скороченням або викладачем. Результати показуються під повідомленням,
по п'ять черг; «Показати всі черги» дозволяє перегляд без запиту.
Повернення з черги відновлює запит і сторінку конкретного студента.

Керування адміністраторами доступне лише власнику:

Налаштування → Адміністратори → Список адміністраторів.

Повернення зі списку веде до керування адміністраторами, звідти — до
налаштувань. Для цих екранів є окремі стани та названі кнопки повернення.
Додавання, видалення й скасування вводу відновлюють правильний стан меню.
Старе натискання «Назад» у цих станах сумісне з новою навігацією. Якщо
стан було втрачено до оновлення, повернення без вибраної черги відкриває
відповідне головне меню замість помилки вибору черги.

Розділ звітів і статистики вилучено з Telegram та мініапки: прибрані
кнопки, сторінки, обробники й API експорту. Старі кнопки повідомляють про
вилучення розділу; старий API повертає 410 після перевірки доступу.
Історія черг, результати лабораторних та інші дані не видаляються.

Список користувачів показується повністю, без сторінок і стрілок. Пошук
та список заблокованих також не обрізаються до перших восьми записів.
Сортування спільне для бота та API мініапки: український алфавіт,
«Ґ» після «Г», «Є» після «Е», «І» й «Ї» перед «Й». Регістр і варіант
апострофа не впливають на порядок. Повернення з картки відкриває весь
список. Лише якщо повідомлення перевищує обмеження Telegram, бот
одразу надсилає список кількома повідомленнями зі спільною нумерацією.
