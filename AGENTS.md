# Правила роботи з проєктом (PI-231 Queue Bot)

1. **Заборона розсилок про оновлення бота:**
   - Ніколи не додавайте нові записи у словник `UPDATES` у файлі `services/updates.py` і не створюйте автоматичних розсилок користувачам про нові версії чи зміни в боті.

2. **Обов'язковий пуш на GitHub після змін:**
   - Після внесення будь-яких змін у код та їх перевірки завжди автоматично виконуйте `git add`, `git commit` та `git push` у віддалений репозиторій (`origin`), не чекаючи окремого прохання від користувача.
